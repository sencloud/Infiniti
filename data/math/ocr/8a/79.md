# 第2章 实数的初步认识
有理数和无理数统称为**实数**（real number）。实数可以分类如下：

| 实数 | 正实数 |
| ---- | ---- |
| | $0$ |
| | 负实数 |

| 实数 | 有理数（整数、有限小数或循环小数） | 无理数（无限不循环小数） |
| ---- | ---- | ---- |

我们知道，有理数可以用数轴上的点来表示，事实上，无理数也可以用数轴上的点来表示。

### 问题
如何在数轴上找到表示$\sqrt{2}$的点？

在章头活动中，我们知道$\sqrt{2}$是图2-4中四个边长为1的小正方形的对角线的长。

（图2-4） （图2-5）

如图2-5，以1个单位长度为边长画一个正方形，这个正方形的对角线长为$\sqrt{2}$。以数轴原点为圆心，正方形的对角线的长为半径画弧，与数轴正半轴的交点就表示$\sqrt{2}$。可见，数轴上并不是所有点都表示有理数。
