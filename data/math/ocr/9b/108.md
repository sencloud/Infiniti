## 7.2 正弦、余弦
根据勾股定理，得
$AB = \sqrt{AC^2 + BC^2} = \sqrt{12^2 + 5^2} = \sqrt{169} = 13.$
根据正弦、余弦的定义，得
$\sin A = \frac{BC}{AB} = \frac{5}{13},\cos A = \frac{AC}{AB} = \frac{12}{13},$
$\sin B = \frac{AC}{AB} = \frac{12}{13},\cos B = \frac{BC}{AB} = \frac{5}{13}.$
### 例4
在 $\text{Rt}\triangle ABC$ 中，$\angle C = 90^\circ$，$\angle A = 15^\circ$，$BC = 6$. 求 $AB$ 的长（精确到 0.01）.
解：由题意知，$\sin A = \frac{BC}{AB}$，
则 $AB = \frac{BC}{\sin A} = \frac{6}{\sin 15^\circ}$.
用计算器计算，得 $AB \approx 23.18$.
