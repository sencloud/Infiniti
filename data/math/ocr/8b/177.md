# 第11章 二次根式
### 例4
计算：
（1）$(\sqrt{3}+\sqrt{2})(\sqrt{3}-\sqrt{2})$；
（2）$(3+2\sqrt{5})^2$．
### 解
（1）$(\sqrt{3}+\sqrt{2})(\sqrt{3}-\sqrt{2}) = (\sqrt{3})^2 - (\sqrt{2})^2 = 3 - 2 = 1$；
（2）$(3+2\sqrt{5})^2 = 3^2 + 2\times3\times2\sqrt{5} + (2\sqrt{5})^2$
$\quad\quad\quad\quad\quad\quad = 9 + 12\sqrt{5} + 20 = 29 + 12\sqrt{5}$．
### 例5
计算：
（1）$(\sqrt{6}+2\sqrt{3})\div\sqrt{3}$；
（2）$\frac{\sqrt{5}}{3+\sqrt{5}}+\frac{\sqrt{5}}{3-\sqrt{5}}$．
### 解
（1）$(\sqrt{6}+2\sqrt{3})\div\sqrt{3} = \frac{\sqrt{6}}{\sqrt{3}}+\frac{2\sqrt{3}}{\sqrt{3}} = \sqrt{2}+2$．
（2）$\frac{\sqrt{5}}{3+\sqrt{5}}+\frac{\sqrt{5}}{3-\sqrt{5}} = \frac{\sqrt{5}(3-\sqrt{5})}{(3+\sqrt{5})(3-\sqrt{5})}+\frac{\sqrt{5}(3+\sqrt{5})}{(3-\sqrt{5})(3+\sqrt{5})}$
$\quad\quad\quad\quad\quad\quad\quad = \frac{3\sqrt{5}-5}{9-5}+\frac{3\sqrt{5}+5}{9-5}$
$\quad\quad\quad\quad\quad\quad\quad = \frac{3\sqrt{5}-5+3\sqrt{5}+5}{9-5} = \frac{6\sqrt{5}}{4} = \frac{3}{2}\sqrt{5}$．
