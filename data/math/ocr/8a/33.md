# 第1章 三角形
### 例8
如图1-26，$AB \perp BD$，$ED \perp BD$，垂足分别为$B$，$D$，点$C$在$BD$上，$AB = CD$，$BC = DE$。求证：$AC$与$CE$垂直且相等。
### 证明
$\because AB \perp BD$，$ED \perp BD$，
$\therefore \angle B = \angle D = 90^\circ$。
在$\triangle ABC$和$\triangle CDE$中，
$\begin{cases}
AB = CD, \\
\angle B = \angle D, \\
BC = DE,
\end{cases}$
$\therefore \triangle ABC \cong \triangle CDE \text{（SAS）}$。
$\therefore \angle A = \angle ECD$，$AC = CE$。
$\because \angle B = 90^\circ$，
$\therefore \angle A + \angle ACB = 90^\circ$。
$\therefore \angle ECD + \angle ACB = 90^\circ$。
$\therefore \angle ACE = 90^\circ$。
$\therefore AC$与$CE$垂直且相等。
（图1-26）
