# 第9章 因式分解
### 探究
写出整式 $A$ 与 $B$，使得 $A = B(a+3)$。满足条件的整式 $A$，$B$ 可以写出多少个？
### 练习
1. 判断下列从左到右的变形中哪些是因式分解。
(1) $ab+ac+d = a(b+c)+d$；
(2) $a^2-1 = (a+1)(a-1)$；
(3) $(a+1)(a-1) = a^2-1$；
(4) $(a+b)(c+d) = ac+ad+bc+bd$。
2. 在下面式子的左边和右边的括号中各填入一个整式，使这个式子的左边与右边相等。
（$\quad$）$=$（$\quad$）$(2a+1)$。
### 习题
1. 判断下列从左到右的变形中哪些是因式分解。
(1) $(x+2)(x-2) = x^2-4$；
(2) $x^2-4 = (x+2)(x-2)$；
(3) $x^2-4+3x = (x+2)(x-2)+3x$；
(4) $x^2+4x+4 = (x+2)^2$。
2. 检验下列因式分解是否正确。
(1) $-12x^3+9x^2 = 3x^2(4x-3)$；
(2) $n^3+3n^2+2n = n(n+1)(n+2)$；
(3) $2x^2-y^2 = (2x+y)(2x-y)$；
(4) $x^2-2xy+y^2 = (-x-y)^2$。
3. 已知多项式 $a^2+6a+k$ 可以分解为 $(a+2)$ 与 $(a+4)$ 的乘积，求 $k$ 的值。
4. $19.3\times\frac{1}{9}+16.7\times\frac{1}{9}$ 能被 2 整除吗？为什么？
