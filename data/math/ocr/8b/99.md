# 第8章 四边形
### 问题
梯形、三角形和平行四边形之间有什么关系？

如图8-42(2)，梯形$ABCD$的顶点$D$在直线$AD$上运动。当点$D$与点$A$重合时，梯形变成了三角形[图8-42(1)]；当$AD=BC$时，梯形变成了平行四边形[图8-42(3)]。

（图8-42）

梯形、三角形、平行四边形的面积之间有如下关系：

| 三角形 | 梯形 | 平行四边形 |
| ---- | ---- | ---- |
| $S_{\triangle ABC}=\frac{1}{2}ah$ | $S_{梯形ABCD}=\frac{1}{2}(a+b)h$ | $S_{▱ABCD}=ah$ |
|  | $b=0$ | $b=a$ |
