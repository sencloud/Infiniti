# 第3章 圆
利用圆心与点的距离可以判断这个点与圆的位置关系，是否也可以利用圆心到直线的距离来判断这条直线与圆的位置关系？
过圆心作直线的垂线，可否通过垂足与圆的位置关系确定直线与圆的位置关系呢？
如图 3-41，圆的半径为 $r$，过圆心作 $OD\perp l$，垂足为 $D$，记圆心 $O$ 到直线 $l$ 的距离为 $d$，则 $d=OD$。
下面分三种情况讨论：
（1） （2） （3）
（图3-41）
1. 如图 3-41(1)，直线 $l$ 与 $\odot O$ 相交。设 $A$，$B$ 为交点，连接 $OA$，则 $OA=r$。在 $\text{Rt}\triangle ADO$ 中，$OD<OA$，即 $d<r$。
反过来，如果 $d<r$，则点 $D$ 在圆内，过点 $D$ 的任意直线都与圆相交，所以直线 $l$ 与 $\odot O$ 相交。
2. 如图 3-41(2)，直线 $l$ 与 $\odot O$ 相切。设 $C$ 为切点，$OC=r$，因为直线 $l$ 上除点 $C$ 外的任意一点 $P$ 都在圆外，$OP>r$，所以 $OC$ 就是圆心 $O$ 到直线 $l$ 的距离，即点 $C$ 与点 $D$ 重合。所以 $d=r$。
反过来，如果 $d=r$，则点 $D$ 是 $\odot O$ 与 $l$ 的一个公共点。因为圆心 $O$ 与直线 $l$ 上其他点的距离都比 $OD$ 大，所以直线 $l$ 上除点 $D$ 外的点都在圆外，即 $\odot O$ 与直线 $l$ 只有一个公共点，所以直线 $l$ 与 $\odot O$ 相切。
3. 如图 3-41(3)，当直线 $l$ 与 $\odot O$ 相离时，$d$ 与 $r$ 有什么关系？反过来成立吗？请与同学讨论。
