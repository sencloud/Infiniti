# 第11章 不等式
## 11.1 不等式
设今年小明$a$岁，小丽$b$岁，那么$a>b$。
3年后小明与小丽的年龄关系可以表示为$a+3>b+3$；
3年前小明与小丽的年龄关系可以表示为$a-3>b-3$。

一般地，我们有**不等式的基本性质1**：
不等式的两边都加上（或减去）同一个数或整式，不等号的方向不变。

可以用符号表示为：如果$a>b$，那么$a\pm c>b\pm c$。

### 例3
如果$a-b<0$，那么是否一定有$a<b$？请说明理由。
### 解
如果$a-b<0$，那么$a<b$。理由如下：
因为$a-b<0$，
在不等式的两边同时加上$b$，得
$a-b+b<0+b$（不等式的基本性质1），
所以$a<b$。
（图11-1）
如果$a<b$，同样能说明$a-b<0$。

在不等式的两边都乘（或除以）同一个数，不等式会有什么变化？下面以“$5>3$”“$-5<-4$”为例进行探究。

### 活动
用不等号填空：
| 不等式 | 两边同乘（或除以）一个正数 | 两边同乘（或除以）一个负数 |
| ---- | ---- | ---- |
| $5>3$ | $5\times2$ $\underline{\quad}$ $3\times2$ | $5\times(-2)$ $\underline{\quad}$ $3\times(-2)$ |
|  | $5\div2$ $\underline{\quad}$ $3\div2$ | $5\div(-2)$ $\underline{\quad}$ $3\div(-2)$ |
| $-5<-4$ | $(-5)\times3$ $\underline{\quad}$ $(-4)\times3$ | $(-5)\times(-3)$ $\underline{\quad}$ $(-4)\times(-3)$ |
|  | $(-5)\div3$ $\underline{\quad}$ $(-4)\div3$ | $(-5)\div(-3)$ $\underline{\quad}$ $(-4)\div(-3)$ |

观察上面各组不等式的不等号方向，你可以得到什么结论？
