### 数学活动
#### 香烟浸出液对种子发芽的影响
吸烟有害人类健康，香烟对植物的生长是否也有害呢？下面我们做一个“香烟浸出液对种子发芽影响”的实验。
实验材料：绿豆若干，清水若干，香烟浸出液 A（2 支香烟浸于 $200\ \mathrm{mL}$ 清水中），香烟浸出液 B（3 支香烟浸于 $200\ \mathrm{mL}$ 清水中），香烟浸出液 C（4 支香烟浸于 $200\ \mathrm{mL}$ 清水中）。
每位学生将绿豆四份（每份 50 粒）分别浸于清水、香烟浸出液 A、香烟浸出液 B、香烟浸出液 C 中，并填表：

| 溶液 | 发芽数目 |  |
| ---- | ---- | ---- |
|  | 第一天 | 第二天 |
| 清水 |  |  |
| 香烟浸出液 A |  |  |
| 香烟浸出液 B |  |  |
| 香烟浸出液 C |  |  |

（1）汇总全组实验数据，分别计算第一天和第二天各种不同溶液中种子发芽数的平均数和方差；
（2）汇总全班实验数据，分别计算第一天和第二天各种不同溶液中种子发芽数的平均数和方差；
（3）香烟浸出液浓度对绿豆发芽率有什么影响？如果再重复这个实验，实验数据是否一致？
（4）选取其他种子（如黄豆）再做一次类似实验；
（5）香烟浸出液浓度对种子发芽率有什么影响？怎样解释这种现象？
