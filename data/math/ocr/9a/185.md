# 第5章 等可能条件下的概率
某地铁站共3个出站口，分别为1号、2号、3号出站口，小明和小亮相约在该地铁站下车会合．他们分别任意选择一个出站口出站，求两人从同一出站口出站的概率．
用表格列举小明、小亮出站的所有可能结果：

| 小亮 | 小明 | | |
| ---- | ---- | ---- | ---- |
| | 1号 | 2号 | 3号 |
| 1号 | （1号，1号） | （1号，2号） | （1号，3号） |
| 2号 | （2号，1号） | （2号，2号） | （2号，3号） |
| 3号 | （3号，1号） | （3号，2号） | （3号，3号） |

由表格可知，共有9种可能的结果，它们的出现是等可能的．记事件$A$为“两人从同一出站口出站”，它包含3种等可能结果，所以
$$P(A)=\frac{3}{9}=\frac{1}{3}.$$
即两人从同一出站口出站的概率是$\frac{1}{3}$．
### 例4
抛掷两枚质地均匀的骰子，求下列随机事件的概率：
（1）两枚骰子朝上一面的点数都是6；
（2）两枚骰子朝上一面的点数之和是7；
（3）两枚骰子朝上一面的点数之和是偶数．

| 2 | （2，1） | （2，2） | （2，3） | （2，4） | （2，5） | （2，6） |
