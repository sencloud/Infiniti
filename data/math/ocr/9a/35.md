# 第1章 一元二次方程
### 例5
某旅行社推出云南跟团游活动，下面是收费信息：

| 旅游人数 | 收费标准 |
| ---- | ---- |
| 不超过30人 | 人均收费4 000元 |
| 超过30人（每团最多50人，报满即止） | 每增加1人，人均收费降低50元 |

这次活动中某团共向旅行社交纳费用14万元，你能确定该团参加活动的人数吗？

### 分析
设该团参加活动的人数为$x$，可以列表分析如下：

| 人数$x$/人 | 人均收费/元 |
| ---- | ---- |
| $x\leqslant30$ | 4 000 |
| $x>30$ | $4\ 000-50(x-30)$ |

### 解
设该团参加活动的共有$x$人，由$4\ 000\times30<140\ 000$，可知$x>30$。
根据题意，得
$$x[4\ 000-50(x-30)]=140\ 000.$$
化简，得
$$x^2-110x+2\ 800=0.$$
解这个方程，得
$$x_1=40,\ x_2=70.$$
因为$70>50$，所以$x=70$不合题意，舍去。
答：该团共有40人参加活动。

### 探究
在例5中，旅行社改进了活动方案，当报名人数少于20人时，每减少1人，人均收费增加100元，其余条件不变。如果某团向旅行社交纳费用67 500元，那么有多少人参加活动？
