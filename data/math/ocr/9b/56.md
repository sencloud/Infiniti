# 第6章 图形的相似
## 6.3 相似图形
解：由三角形中位线的性质，知
$EF \parallel BC$，$DE \parallel AB$，$DF \parallel AC$；
$EF = \frac{1}{2}BC$，$DE = \frac{1}{2}AB$，$DF = \frac{1}{2}AC$。
于是，在$\parallelogram AFDE$、$\parallelogram BDEF$、$\parallelogram CEFD$中，
$\angle EDF = \angle A$，$\angle DEF = \angle B$，$\angle DFE = \angle C$。
又因为$\frac{EF}{BC} = \frac{DE}{AB} = \frac{DF}{AC} = \frac{1}{2}$，
所以$\triangle DEF \backsim \triangle ABC$。
