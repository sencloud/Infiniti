# 第7章 锐角三角函数
## 7.3 特殊角的三角函数
### 思考与探索
请说出$30^\circ$、$45^\circ$、$60^\circ$角的各三角函数值，并说明理由。
$30^\circ$、$45^\circ$、$60^\circ$角的三角函数值列表如下：

| $\theta$ | 三角函数值 |  |  |
| ---- | ---- | ---- | ---- |
|  | $\sin\theta$ | $\cos\theta$ | $\tan\theta$ |
| $30^\circ$ | $\frac{1}{2}$ | $\frac{\sqrt{3}}{2}$ | $\frac{\sqrt{3}}{3}$ |
| $45^\circ$ | $\frac{\sqrt{2}}{2}$ | $\frac{\sqrt{2}}{2}$ | $1$ |
| $60^\circ$ | $\frac{\sqrt{3}}{2}$ | $\frac{1}{2}$ | $\sqrt{3}$ |

（图7-3）

### 例1
求下列各式的值：
（1）$2\sin30^\circ-\cos45^\circ$；
（2）$\sin60^\circ\cos60^\circ$；
（3）$\tan30^\circ+\cos30^\circ$。

解：（1）$2\sin30^\circ-\cos45^\circ=2\times\frac{1}{2}-\frac{\sqrt{2}}{2}=\frac{2-\sqrt{2}}{2}$；
（2）$\sin60^\circ\cos60^\circ=\frac{\sqrt{3}}{2}\times\frac{1}{2}=\frac{\sqrt{3}}{4}$；
（3）$\tan30^\circ+\cos30^\circ=\frac{\sqrt{3}}{3}+\frac{\sqrt{3}}{2}=\frac{5\sqrt{3}}{6}$。
