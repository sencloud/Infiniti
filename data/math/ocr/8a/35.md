# 第1章 三角形
如图1-27，给定直角三角形$ABC$，其中$\angle C=90^\circ$，简记为“$\text{Rt}\triangle ABC$”。用直尺和圆规作$\text{Rt}\triangle A'B'C'$，使得$\angle C'=90^\circ$，$A'B'=AB$，$A'C'=AC$。这两个三角形全等吗？
（图1-27）
下面是$\text{Rt}\triangle A'B'C'$的作法：
| 作法 | 图形 |
| ---- | ---- |
| 1. 作$\angle PC'Q=90^\circ$.<br>2. 在射线$C'P$上截取$A'C'=AC$.<br>3. 以点$A'$为圆心，$AB$长为半径作弧，交射线$C'Q$于点$B'$.<br>$\text{Rt}\triangle A'B'C'$即为所求. | （图） |

我们可以证明$\triangle ABC\cong\triangle A'B'C'$：
如图1-28，在$\text{Rt}\triangle ABC$和$\text{Rt}\triangle A'B'C'$中，$\angle C=\angle C'=90^\circ$，$AB=A'B'$，$AC=A'C'$。
（图1-28）（图1-29）
如图1-29，将$\triangle ABC$和$\triangle A'B'C'$分别沿$BC$和$B'C'$翻折，得到$\triangle ABP$和$\triangle A'B'Q$。通过“SSS”，可证$\triangle ABP\cong\triangle A'B'Q$，由此可知$\angle A=\angle A'$。通过“SAS”，可证$\text{Rt}\triangle ABC\cong\text{Rt}\triangle A'B'C'$。
于是，我们得到如下定理：
斜边和一条直角边分别相等的两个直角三角形全等（简写成“HL”）。
