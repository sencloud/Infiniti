## 8.2 矩形的判定
矩形的四个角都是直角，对角线相等．反过来，一个四边形满足哪些条件就一定是矩形呢？
### 问题
四个角都是直角的四边形是矩形吗？
如图 8-19，在四边形 $ABCD$ 中，$\angle A = \angle B = \angle C = \angle D = 90^\circ$，可得 $\angle A+\angle B=180^\circ$，$\angle B+\angle C=180^\circ$．于是 $AD \parallel BC$，$AB \parallel DC$．又因为 $\angle A = 90^\circ$，所以四边形 $ABCD$ 是矩形．
