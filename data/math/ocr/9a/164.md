## 4.4 数据的离散程度
第二组的离差平方和
$$S_b^2 = (x_{m+1} - \overline{x}_b)^2 + (x_{m+2} - \overline{x}_b)^2 + \cdots + (x_n - \overline{x}_b)^2,$$
$S_a^2 + S_b^2$ 称为组内离差平方和.
研究表明，当 $S_a^2 + S_b^2$ 达到最小时，分组较合理，可以将“组内离差平方和达到最小”作为数据的分组标准.
### 例
在学校“国风·文化”主题体验日活动中，某班级计划把 6 种不同进价的传统文创分成两组，对同组文创采取相同的定价，以方便在义卖中销售.

| 品种 | 书签 | 香包 | 剪纸 | 毛笔 | 折扇 | 木梳 |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| 进价/元 | 5.5 | 7.5 | 6.5 | 8.0 | 9.5 | 9.0 |

请按进价的组内离差平方和最小的标准将这 6 种文创分成两组.
### 解
先将 6 个数据按从小到大的顺序排列：
$$5.5,\ 6.5,\ 7.5,\ 8.0,\ 9.0,\ 9.5.$$
然后，将这些数据依次分为两组，共有五种情况，计算各组离差平方和，可以得到下面的结果：

| 分类情况 | 组内离差平方和 |
| ---- | ---- |
| 第一组1个，第二组5个 | 5.70 |
| 第一组2个，第二组4个 | 3.00 |
| 第一组3个，第二组3个 | 3.17 |
| 第一组4个，第二组2个 | 3.81 |
| 第一组5个，第二组1个 | 7.30 |

根据上表，将排序后的前 2 个数据分为一组、后 4 个数据分为另一组，可以使组内离差平方和最小. 依据数据对应的文创，分组方案为｛书签、剪纸｝｛香包、毛笔、折扇、木梳｝.
