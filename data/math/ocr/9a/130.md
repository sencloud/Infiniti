# 第4章 平均数
## 4.1 平均数
### 加权平均数
在例2中，为了更合理地估计裸鲤的平均质量，在湖区中又连续进行了第2次、第3次随机捕捞，结果见下表。如何计算三次捕捞的所有裸鲤的平均质量（结果精确到1 g/尾）？

| 捕捞次序 | 捕捞数量/尾 | 平均质量/（g/尾） |
| -------- | ----------- | ----------------- |
| 第1次    | 15          | 267               |
| 第2次    | 28          | 260               |
| 第3次    | 25          | 252               |

可以求三个平均质量的平均数。
应该先求出68尾裸鲤的总质量，再求平均数。

68尾裸鲤的总质量为
$$15\times267+28\times260+25\times252=17\ 585\ \mathrm{(g)}$$
68尾裸鲤的平均质量为
$$\frac{17\ 585}{15+28+25}\approx259\ \mathrm{(g/尾)}$$
因此，这68尾裸鲤的平均质量约为259 g/尾。

一组数据的平均数，不仅与这组数据中各个数据的值有关，而且与各个数据的“重要程度”有关。我们把衡量各个数据“重要程度”的数值叫作**权**（weight），也称为权重。例如，问题中267，260和252分别是15尾、28尾和25尾裸鲤质量数据的平均数，它们分别占总量的$\frac{15}{68}$，$\frac{28}{68}$和$\frac{25}{68}$，利用267，260和252计算68尾裸鲤的平均质量时应该分别乘各自的权重，得到**加权平均数**（weighted average）。
