2. 判断命题“如果$a<b$，$c<d$，那么$a+c<b+d$”的真假性。

| 因为$a<b$， | 命题的条件 |
| ---- | ---- |
| 在不等式两边都加上$c$，得<br>$a+c<b+c$。 | 不等式的基本性质 |
| 因为$c<d$， | 命题的条件 |
| 在不等式两边都加上$b$，得<br>$b+c<b+d$。 | 不等式的基本性质 |
| 因为$a+c<b+c$，$b+c<b+d$，<br>所以$a+c<b+d$。 | 根据传递性，得到命题的结论 |

所以，命题“如果$a<b$，$c<d$，那么$a+c<b+d$”为真命题。

像上面这样，从命题的条件出发，根据一些已知的事实（如概念的定义，基本性质，真命题等），用“因为……，所以……”的形式一步一步推出命题的结论，从而确定这个命题为真命题的过程称为**证明**（proof）。

### 例1
证明：三个连续自然数之和能被3整除。
### 证明
设这三个自然数分别为$k-1$，$k$，$k+1$，其中$k\geqslant1$。
所设三个自然数的和为$(k-1)+k+(k+1)=3k$。
因为$3k$能被3整除，
所以这三个自然数的和能被3整除。

为了书写方便，在证明过程中，也可以用“$\because$”表示“因为”，用“$\therefore$”表示“所以”。
