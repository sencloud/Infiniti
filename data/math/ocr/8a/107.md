# 第3章 勾股定理
### 例2
如图 3 - 14，$CD$ 为 $\text{Rt}\triangle ABC$ 的斜边 $AB$ 上的高，设 $CD=h$，$AD=m$，$DB=n$．求证：$h^2=mn$．
### 证明
$\because CD$ 是 $\text{Rt}\triangle ABC$ 的高，
$\therefore \angle CDA = \angle CDB = 90^\circ$．
在 $\text{Rt}\triangle ADC$ 中，根据勾股定理，得
$AC^2 = h^2 + m^2$．
在 $\text{Rt}\triangle DBC$ 中，根据勾股定理，得
$BC^2 = h^2 + n^2$．
在 $\text{Rt}\triangle ABC$ 中，根据勾股定理，得
$AC^2 + BC^2 = AB^2$．
$\because AB=m+n$，
$\therefore h^2 + m^2 + h^2 + n^2 = (m+n)^2$．
$\therefore h^2=mn$．
