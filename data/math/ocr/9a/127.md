# 第4章 数据的集中趋势和离散程度
## 4.1 平均数
### 算术平均数
### 讨论
某地举行了一场象棋友谊赛，参赛年龄不限。12名选手被随机分为甲、乙两组，两个小组选手的平均年龄相近。这里的“平均年龄”是什么意思？

一般地，如果有$n$个数
$$x_1,\ x_2,\ \cdots,\ x_n,$$
那么
$$\overline{x}=\frac{x_1+x_2+\cdots+x_n}{n}$$
叫作这$n$个数的算术平均数（arithmetic mean），简称为平均数，通常用$\overline{x}$表示。“$\overline{x}$”读作“$x$拔”。

### 例1
A，B两个小组的学生身高如下（单位：cm）：

| A组 | B组 |
| ---- | ---- |
| 164 168 171 166 | 166 172 170 162 |
| 170 168 166 164 | 164 169 180 165 |
| 169 182 166 168 | 167 168 |

比较A，B两组学生的平均身高。
