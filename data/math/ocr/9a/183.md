# 第5章 等可能条件下的概率
你认为小明、小慧说的结果哪个是等可能的？
### 讨论
我们可以用图5-3列出所有可能的结果：

（图5-3）
两次抛掷后得到4种结果，这些结果都是等可能的，其概率都是$\frac{1}{4}$。
像图5-3这样的图称为树状图（tree derivation），它直观地显示了一个随机事件在试验中所有可能的结果。通过画树状图或列表列出这些结果，可以做到既不重复，又不遗漏。
### 例3
小明的衣柜中有红色、黄色、蓝色上衣各1件，有蓝色、棕色裤子各1条。小明从中任意取出1件上衣和1条裤子，恰好取到蓝色上衣和蓝色裤子的概率是多少？取到棕色裤子的概率是多少？
### 解
用表格列举所有可能的结果：

| 上衣颜色 | 裤子颜色 |  |
| ---- | ---- | ---- |
|  | 蓝 | 棕 |
| 红 | （红衣，蓝裤） | （红衣，棕裤） |
| 黄 | （黄衣，蓝裤） | （黄衣，棕裤） |
| 蓝 | （蓝衣，蓝裤） | （蓝衣，棕裤） |
