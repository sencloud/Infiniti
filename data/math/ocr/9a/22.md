# 第1章 一元二次方程
## 1.2 一元二次方程的解法
下面我们用配方法解一般形式的一元二次方程：
$ax^2 + bx + c = 0(a \neq 0)$．
因为$a \neq 0$，所以可在方程两边都除以$a$，得
$x^2 + \frac{b}{a}x + \frac{c}{a} = 0$． 化为$x^2 + px + q = 0$的形式
移项，得
$x^2 + \frac{b}{a}x = -\frac{c}{a}$．
配方，得
$x^2 + 2 \cdot \frac{b}{2a} \cdot x + \left( \frac{b}{2a} \right)^2 = -\frac{c}{a} + \left( \frac{b}{2a} \right)^2$．
即
$\left( x + \frac{b}{2a} \right)^2 = \frac{b^2 - 4ac}{4a^2}$． 化为$(x+h)^2 = k$的形式
因为$4a^2 > 0$，
所以当$b^2 - 4ac \geqslant 0$时，
$x + \frac{b}{2a} = \pm \frac{\sqrt{b^2 - 4ac}}{2a}$．
所以
$x = -\frac{b}{2a} \pm \frac{\sqrt{b^2 - 4ac}}{2a}$
$= \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$．
当$b^2 - 4ac < 0$时，方程无实数根．
这样，我们就得到
一元二次方程$ax^2 + bx + c = 0(a \neq 0)$的求根公式：
$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \quad (b^2 - 4ac \geqslant 0)$．
