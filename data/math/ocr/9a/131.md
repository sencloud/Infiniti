# 第4章 数据的集中趋势和离散程度
一般地，若$n$个数据$x_1$，$x_2$，$\cdots$，$x_n$的权分别为$w_1$，$w_2$，$\cdots$，$w_n$，则加权平均数为
$$\overline{x}=\frac{x_1w_1+x_2w_2+\cdots+x_nw_n}{w_1+w_2+\cdots+w_n}.$$
当$w_1+w_2+\cdots+w_n=1$时，$\overline{x}=x_1w_1+x_2w_2+\cdots+x_nw_n$.
### 例3
在一次黑板报评比中，九年级三个班级的各项得分如下：

| 班 级 | 版面设计 | 书写绘画 | 创意设计 |
| ---- | ---- | ---- | ---- |
| 甲班 | 70分 | 60分 | 86分 |
| 乙班 | 90分 | 75分 | 51分 |
| 丙班 | 60分 | 84分 | 78分 |

（1）若将版面设计、书写绘画和创意设计3项得分的平均分作为总评成绩，哪个班级的总评成绩最高？
（2）若版面设计、书写绘画和创意设计的得分按$5:2:3$计入总评成绩，哪个班级的总评成绩最高？
### 解
（1）甲班的总评成绩$=\frac{70+60+86}{3}=72$（分），
乙班的总评成绩$=\frac{90+75+51}{3}=72$（分），
丙班的总评成绩$=\frac{60+84+78}{3}=74$（分），
所以，丙班的总评成绩最高.
（2）版面设计、书写绘画和创意设计的权分别为$\frac{5}{5+2+3}$，
$\frac{2}{5+2+3}$，$\frac{3}{5+2+3}$.
甲班的得分$=70\times\frac{5}{10}+60\times\frac{2}{10}+86\times\frac{3}{10}$
$=\frac{70\times5+60\times2+86\times3}{10}=72.8$（分），
乙班的得分$=\frac{90\times5+75\times2+51\times3}{10}=75.3$（分），
丙班的得分$=\frac{60\times5+84\times2+78\times3}{10}=70.2$（分），
所以，乙班的总评成绩最高.
