# 第8章 四边形
如图8-12，在四边形$ABCD$中，对角线$AC$，$BD$相交于点$O$，
$OA = OC$，$OB = OD$。
由$OA = OC$，$\angle AOB = \angle COD$，
$OB = OD$，可得$\triangle AOB \cong \triangle COD$，于是
$AB = CD$。同理可得$AD = CB$。
所以四边形$ABCD$是平行四边形。
（图8-12）
于是，我们得到**平行四边形的判定定理3**：
对角线互相平分的四边形是平行四边形。
如图，在四边形$ABCD$中，
对角线$AC$，$BD$相交于点$O$。
如果$OA=OC$，$OB=OD$，
那么四边形$ABCD$是平行
四边形。
### 例4
如图8-13，在$\parallelogram ABCD$中，点$E$，$F$在对角线$AC$上，$AE = CF$。连接$BE$，$ED$，$DF$，$FB$。求证：四边形$BFDE$是平行四边形。
（图8-13）
### 证明
如图8-14，连接$BD$，交$AC$于点$O$。
$\because$ 四边形$ABCD$是平行四边形，
$\therefore OA = OC$，$OB = OD$。
$\because AE = CF$，
$\therefore OA - AE = OC - CF$，
即 $OE = OF$。
$\therefore$ 四边形$BFDE$是平行四边形（平行四边形的判定定理3）。
（图8-14）
