# 第5章 等可能条件下的概率
## 5.4 概率的应用——概率帮你做估计
### 数学实验室
一只不透明的袋子中装有若干个白球和红球，这些球除颜色外都相同．做摸球试验：
（1）两人一组，一人从袋子中任意摸出1个球，另一人记下颜色后将球放回并搅匀，连续做50次这样的试验；
（2）整理数据，并填表：

| 球的颜色 | 白色 | 红色 |
| -------- | ---- | ---- |
| 频数     |      |      |
| 频率     |      |      |

根据试验的结果，你能估计袋子中白球数与红球数的比吗？
假设某人摸球400次，摸到白球40次，且已知袋子中有白球5个，你能估计袋子中红球的个数吗？

由400次摸球中摸到白球的频数为40，可知摸到白球的频率为0.1．当试验次数很大时，用频率作为概率的估计值，可以估计摸到白球的概率为0.1．
设袋子中有红球$x$个，则袋子中共有球$(x+5)$个，从袋子中任意摸出1个球是白球的概率为$P(\text{摸到白球})=\frac{5}{x+5}$．
由$\frac{5}{x+5}=0.1$，得$x=45$．
这样，我们可以估计袋子中有红球45个．
