# 第10章 二元一次方程组
## 10.5 用二元一次方程组解决问题
### 例3
劳动周中，某小组计划做一批“中国结”，如果每人做5个，那么可比计划多做9个；如果每人做4个，那么将比计划少做15个．该小组共有多少人？计划做多少个“中国结”？
### 分析
设该小组共有$x$人，计划做$y$个“中国结”．可以列表分析数量关系：

| 方案 | 每人做的个数/个 | 做的总个数/个 | 与计划数比较 |
| ---- | ---- | ---- | ---- |
| 方案一 | 5 | $5x$ | 多9个 |
| 方案二 | 4 | $4x$ | 少15个 |

### 解
设该小组共有$x$人，计划做$y$个“中国结”．
根据题意，得
$$\begin{cases}5x - y = 9,\\y - 4x = 15.\end{cases}$$
解这个方程组，得
$$\begin{cases}x = 24,\\y = 111.\end{cases}$$
答：该小组共有24人，计划做111个“中国结”．
