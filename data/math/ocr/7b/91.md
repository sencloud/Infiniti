# 第10章 二元一次方程组
我们已经学习过一元一次方程的概念、解法与应用，本章将学习二元一次方程组的概念、解法与应用。

解二元一次方程组的基本思路是通过消元将其转化为一元一次方程。应用二元一次方程组解决实际问题的关键是借助表格或示意图寻找等量关系。

二元一次方程组是解决问题的常用工具，许多含有两个未知量的实际问题可以通过建立二元一次方程组求解。

| 项目 | 甲车 | 乙车 | 等量关系 |
| ---- | ---- | ---- | -------- |
| 路程 | $x\ \mathrm{km}$ | $y\ \mathrm{km}$ | $x+y=200$ |
| 时间 | $\frac{x}{220}\ \mathrm{h}$ | $\frac{y}{180}\ \mathrm{h}$ | $\frac{x}{220}=\frac{y}{180}$ |
