### 证明
$\because$ 四边形 $ABCD$ 是正方形，
$\therefore \angle A = \angle B = \angle C = \angle D = 90^\circ$，
$AB = BC = CD = DA$（正方形的性质定理）。
$\because AA' = BB' = CC' = DD'$，
$\therefore D'A = A'B = B'C = C'D$。
$\therefore \triangle AA'D' \cong \triangle BB'A' \cong \triangle CC'B' \cong \triangle DD'C'$。
$\therefore D'A' = A'B' = B'C' = C'D'$。
$\therefore$ 四边形 $A'B'C'D'$ 是菱形。
由 $\triangle AA'D' \cong \triangle BB'A'$，可得 $\angle AD'A' = \angle BA'B'$。
$\because \angle A = 90^\circ$，
$\therefore \angle AA'D' + \angle AD'A' = 90^\circ$。
$\therefore \angle AA'D' + \angle BA'B' = 90^\circ$。
$\therefore \angle D'A'B' = 90^\circ$。
$\therefore$ 四边形 $A'B'C'D'$ 是正方形（正方形的判定定理）。
