# 第10章 二元一次方程组
### 习题
1. 用代入法解下列方程组：
(1) $\begin{cases}2x + 4y = 5,\\x = 1 - y;\end{cases}$
(2) $\begin{cases}3y = 7 + x,\\2x = 5y;\end{cases}$
(3) $\begin{cases}u + v = 10,\\3u - 2v = 5;\end{cases}$
(4) $\begin{cases}3x + 2z = 11,\\3x - 5z = 4.\end{cases}$
2. 用加减法解下列方程组：
(1) $\begin{cases}3x - 4y = 1,\\5x + 2y = 6;\end{cases}$
(2) $\begin{cases}3x + 5y = 25,\\4x + 3y = 15;\end{cases}$
(3) $\begin{cases}2x - 3y = 8,\\7x - 5y = -5;\end{cases}$
(4) $\begin{cases}\frac{x}{2} + \frac{y}{3} = 16,\\\frac{x}{3} - \frac{y}{4} = 5.\end{cases}$
3. 在等式 $y=ax+b$（$a$，$b$ 是常数）中，当 $x=5$ 时，$y=6$；当 $y=-10$ 时，$x=-3$. 求 $a$，$b$ 的值.
