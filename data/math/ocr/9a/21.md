# 第1章 一元二次方程
### 例5
用因式分解法解方程：$(2x-1)^2-x^2=0$．
### 解
原方程可变形为
$$(2x-1+x)(2x-1-x)=0,$$
$$(3x-1)(x-1)=0.$$
$$3x-1=0 \text{或} x-1=0.$$
所以原方程的两个实数根为$x_1=\frac{1}{3}$，$x_2=1$．
### 讨论
小明解方程$(x+2)^2=4(x+2)$的过程如下：
| 原方程两边都除以$(x+2)$，得 |
| --- |
| $x+2=4.$ |
| 解得 |
| $x=2.$ |
| 所以原方程的实数根是$x=2$. |
小明的解法正确吗？
### 练习
1. 用因式分解法解下列方程：
（1）$x^2-3x=0$； （2）$3x^2=x$；
（3）$2(x-1)+x(x-1)=0$； （4）$4x(2x-1)=3(2x-1)$．
2. 用因式分解法解下列方程：
（1）$(x+1)^2-9=0$；
（2）$(x-2)^2-9(x+1)^2=0$．
