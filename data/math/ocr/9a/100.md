# 第3章 圆
## 3.5 点与圆、直线与圆的位置关系
由此可得圆的切线性质定理：
### 圆的切线垂直于经过切点的半径．
### 例3
如图 3 - 44，$\triangle ABC$ 是 $\odot O$ 的内接三角形，$AC$ 是 $\odot O$ 的直径，$\angle BAD = \angle ACB$．判断直线 $AD$ 与 $\odot O$ 的位置关系，并加以证明．
### 解
直线 $AD$ 与 $\odot O$ 相切．证明如下：
$\because AC$ 是 $\odot O$ 的直径，
$\therefore \angle ABC = 90^\circ$．
$\therefore \angle ACB + \angle BAC = 90^\circ$．
$\because \angle BAD = \angle ACB$，
$\therefore \angle BAD + \angle BAC = 90^\circ$．
$\therefore AD \perp AC$．
$\therefore$ 直线 $AD$ 与 $\odot O$ 相切（圆的切线判定定理）．
（图3-44）
### 例4
如图 3 - 45，$AB$ 是 $\odot O$ 的直径，弦 $AD$ 平分 $\angle BAC$，过点 $D$ 的切线交 $AC$ 于点 $E$．
求证：$DE \perp AC$．
（图3-45）
### 证明
如图 3 - 46，连接 $OD$．
$\because OD = OA$，
$\therefore \angle ODA = \angle OAD$．
$\because AD$ 平分 $\angle BAC$，
$\therefore \angle OAD = \angle CAD$．
$\therefore \angle ODA = \angle CAD$．
$\therefore OD \parallel AC$．
$\therefore \angle ODE + \angle AED = 180^\circ$．
$\because DE$ 是 $\odot O$ 的切线，
$\therefore DE \perp OD$（圆的切线性质定理），
即 $\angle ODE = 90^\circ$．
$\therefore \angle AED = 90^\circ$．
$\therefore DE \perp AC$．
（图3-46）
